# MVS 가창 작업실 🐾

## 1. 받은 자료를 실행 계약으로 바꾸기

요청에 이미 답이 있으면 재확인하지 않는다. 입력이 서로 충돌하거나 결과를 바꿀 중요한 값만 모아 묻고, 확인된 나머지는 먼저 정리한다. 원본 파일은 수정하지 않는다.

- **가사:** 사용자가 제공했거나 그 용도로 사용할 권리가 확인된 내용과 언어. TXT는 시간 정보가 없으며 일반 LRC는 줄의 기준 시각만 준다. 명시적 음절 타이밍·악보가 있으면 우선한다.
- **음정:** 음표마다 시작, 지속시간, MIDI 번호 또는 Hz, 필요하면 가사 음절 연결과 쉼표. MIDI·MusicXML은 기준 편곡과 보컬 트랙을 확인한다. 멜리스마나 붙임줄은 음표마다 음절을 새로 할당하지 않는다.
- **반주:** 요청했을 때만 사용. 권한, 기준 버전 및 오프셋을 확인하고 전주와 쉼표에는 보컬을 넣지 않는다. 가사 링크나 MR만으로 원래 악보를 만들어 내지 않는다.
- **출력:** 음악만인지, 음악과 전체 작업실 화면을 별도로 달라는 것인지 구분한다. 기본적으로 사용자 파일은 로컬 작업 공간에 둔다.

정확도가 필요한데 음정이나 음절 시간이 비었으면 비어 있는 위치를 알린다. 자동 추정을 요청한 경우에만 해당 시각과 근거를 ‘추정’으로 표시하고 사용자가 고칠 수 있게 한다. 제공처를 이용하라는 요청은 그 사이트의 화면을 읽었다는 것과 같지 않다. 공식 API와 가사 이용 범위가 확인될 때만 본문을 가져오고, 실패하면 권한 있는 파일 직접 넣기를 제안한다.

## 2. 실행 가능한 경로만 선택

[프로젝트 지침](../../../AGENTS.md) → [작업실 사용법](../../../docs/mvs/STUDIO.md) → 필요한 경우 [장기 가창 설계](../../../docs/mvs/SINGING.md)를 읽는다. 실제 실행 경로와 입력 예시는 현재 브랜치의 도움말, 예제, 검증 코드에서 확인한다. `node studio/cli.mjs validate score.json`을 먼저 실행한 뒤 `render`는 WAV로, `show`는 재생용 HTML로 구분한다. 설계의 JSON은 명시적으로 구현 표기가 되기 전에는 실행 입력으로 가정하지 않는다.
가사가 포함된 단선율 MusicXML은 사용법의 `python3 studio/musicxml.py`로 로컬 JSON으로 바꾸고, 절·템포·쉼표·붙임줄을 원본과 대조한다. 미지원 기호를 임의 삭제하거나 누락 가사를 보충하지 않는다.

- **음악만:** 로컬 파일로 검증한 스코어를 네이티브 렌더러 또는 앱의 오디오 내보내기로 실행한다. 요청에 맞춰 보컬 단독, MR 포함 믹스 또는 둘 다 만든다. 영상이나 스크린샷을 성과로 대신하지 않는다.
- **작업실 화면 포함:** 같은 프로젝트·프리셋·악보로 화면과 오디오를 만든다. 재생용 무대가 충분하면 `show`로 독립 HTML을 만들고, 전체 편집 흐름이나 영상이 필요하면 실제 작업실을 캡처한다. 재생 헤드와 하이라이트가 실제 오디오 위치를 따라가는지 확인한다. 스크린샷은 조작 상태를 보여 주는 보조 자료이고 영상 자체는 아니다. 내장 출력이 없으면 실제 로컬 앱을 화면 녹화하고 그 렌더의 오디오와 합칠 수 있다. 화면만 성공하면 ‘화면만 확인’이라고 말한다.
- 가사·음정 입력을 바꾸지 말고 렌더가 지원하지 않는 기능을 ‘완료’라고 적지 않는다. 엔진과 파일 형식이 정확한 시간을 표현하지 못하면 허용 오차와 손실을 명시한다. 진짜 고양이 물리 모델이나 실존 인물 목소리라고 과장하지 않는다.

## 3. 전달하기 전 실제 결과를 확인

1. 출력 파일이 비어 있지 않은지, 코덱·채널·샘플레이트·실제 길이를 확인한다.
2. 첫 음절, 마지막 음절, 첫 쉼표를 실제 재생 또는 분석으로 확인한다. 준비된 악보의 시각과 비교하고, 안정된 모음만 F0 검사 대상으로 삼는다. 시작 시각과 선행 자음은 같지 않다.
3. 무음은 전주·쉼표인지 오류인지 구분한다. 보컬과 반주 길이, 피크·클리핑, 영상과 오디오의 싱크를 각각 확인한다.
4. 실행 명령과 남은 한계를 적고 요청한 파일만 전달한다. 테스트는 권리가 정리된 짧은 자체 샘플로 재현한다. 실사용 파일이나 토큰은 커밋·릴리즈에 넣지 않는다.

- 재생 무대 MP4가 명시되면 `show` 다음에 `python3 studio/film.py stage.html stage.mp4`를 쓸 수 있다. Chromium과 FFmpeg가 필요하고, 최대 30초다. 작업실 조작 화면과 재생 무대를 혼동하지 않는다.
