# MVS 제품 비전

## 1. 목표와 원칙

1. 실제 고양이 발성에 가까운 물리 모델의 탐색: 야옹, 골골송, 하악질, 거친 울음, 트릴 등.
2. 인간의 언어 명료도를 유지하면서 고양이의 공명과 발성 특성을 선택적으로 섞는 가상 보컬 설계.
3. 가사·시간·음정·반주를 동기화하여 자동으로 노래하는 가상 가수.
4. 브라우저에서 접근 가능한 연구 도구와 편집기, 재현 가능한 오프라인 렌더.
5. 성대, 기도, 혀, 턱, 입술과 공기의 상태를 시각적으로 보여주는 발성기관 디지털 트윈.

생물학적으로 실제 존재하는 종과 창작용 가상 종을 구분한다. 혼합비는 실제 유전자 비율이 아니라 엔진 제어값이다. 자연스러움은 가정하지 말고 청취와 수치로 평가한다.

## 2. 사용 시나리오

- **먀용 실험실**: 고양이 울음의 피치, 호흡압, 성문 개방, 입 벌림과 발성 길이를 조작한다.
- **FELINE-01**: 한국어 가사를 말하고 노래하는 고양이풍 인간 보컬. 인간의 조음 체계를 기본으로 유지한다.
- **노래방**: 가사 파일, 음표 또는 MIDI/MusicXML, MR을 불러온다. 자동 정렬 결과를 고친 뒤 재생한다. 전주에는 침묵하고 지정된 시간에 가창한다.
- **스튜디오**: 음절별 피아노 롤, 가사 하이라이트, 재생/정지/탐색, 루프, 반주/보컬 볼륨, 키 변경, 미리듣기, WAV 및 프로젝트 저장.
- **생체음향 뷰어**: 인체/고양이/가상의 단면을 보여주고 기도 압력, 유량, 성문, 포먼트, 스펙트럼, F0를 동기화한다.

## 3. 기능 범위

| 단계 | 기능 |
|---|---|
| 핵심 | 고양이 프리셋, 고양이풍 인간 발성, 음절/음표 매핑, MR과 자동 가창, 오프라인 출력 |
| 후속 | 음정 자동 추출, 가사 강제 정렬, 세밀한 음소 편집, 실시간 렌더 및 3D 애니메이션 |
| 연구 | 듀엣, 합창(예: 100마리; 오프라인 우선), 골골송 베이스, 다양한 동물 하이브리드, 멸종동물의 추정 발성 |
| 장기 | IRIS의 대화 에이전트가 텍스트와 감정 제어를 보내는 음성 모듈, 가상 생물의 발성기관 설계 SDK |

강아지/사자 등은 별도 종의 해부학적 근거가 필요하다. 멸종동물은 실증된 복원이 아니라 가설에 따른 소리로 표시한다. LLM은 선택적 텍스트/운율 제어기이며 물리 합성 자체의 필수 의존성이 아니다.

## 4. 제품 원칙

브라우저 로컬 우선; 개인 프로젝트/음원은 사용자 명시 선택 없이는 외부 전송하지 않는다. 노래 전체 자동화보다 정확한 타임라인과 안정적인 발성을 먼저 만든다. 가사·MR·악보·참고 녹음의 이용권한과 출처를 각각 관리한다. 합성 보컬과 반주를 분리 저장한다. 기존 엔진의 인간 음색을 무단 변경하지 않는다.
