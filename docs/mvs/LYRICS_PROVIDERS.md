# 가사 공급처 검증표 · 가사가 있다고 음정도 있는 건 아니다

**원칙:** 가사 본문, 타임스탬프, 음정, 반주 원본, 완성본 공개에는 각각 다른 출처·권한이 필요할 수 있다. API 응답이 오거나 앱에 가사가 보인다는 사실만으로 자동 수집, 변환, 학습, 가창 합성 또는 재배포 권리가 생기지는 않는다. 첫 재현 예제는 직접 쓴 가사와 자체 음정 데이터로 검증한다.

| 공급처·입력 | 실제 확인 범위 | 프로젝트 기본 동작 |
| --- | --- | --- |
| [벅스 공식 패널](https://music.bugs.co.kr/panel) · [공식 플레이어](https://music.bugs.co.kr/newPlayer) | 공식 자료에서 이용자용 가사 표시/패널 등록 경로를 확인. 외부에 공식적으로 공개된 범용 가사 API나 합성 사용 권한은 확인하지 못했다. 작업 셸에서 패널 URL 직접 조회는 HTTP 503이었다. | 공식 서비스 링크로 안내만 한다. 로그인·앱 내부 호출·페이지 파싱으로 대체하지 않는다. 정식 제휴 계약과 문서가 있을 때 별도로 검증한다. |

HTTP 200, 정상 JSON 20건, 제목·아티스트·앨범·길이와 싱크/본문 보유 플래그 확인. 응답에 `plainLyrics`, `syncedLyrics`, `lyricsfile` 본문 필드 없음. 베타 메타데이터 결과만 검증했다. | 사용자가 검색을 요청했을 때 곡 후보 및 정렬 여부만 탐색하는 옵션. 가사 본문을 자동으로 받아 노래로 만들거나 저장하지 않는다. 음표 데이터가 아니며 베타 변경에 대비한다. |

확인 시점: 2026-11-28 KST. 운영 환경의 공급처 가용성을 보장하는 검증은 아니다.

## 메타데이터 조회 재현

아래 검색은 공급사가 문서화한 **본문 없는** 경로다. 명령은 필드명과 건수만 출력하며 응답을 파일로 보관하지 않는다. 베타와 카탈로그 결과는 바뀔 수 있다.

```sh
curl -fsS --max-time 10 -G 'https://lrclib.net/api/v2/search' \
  --data-urlencode 'track_name=Daisy Bell' \
  -A 'MVS/0.1 (https://github.com/hslcrb/meow-voice-system)' |
python3 -c 'import json,sys; x=json.load(sys.stdin); assert isinstance(x,list); assert all(not ({"plainLyrics","syncedLyrics","lyricsfile"} & set(i)) for i in x); print(len(x), sorted(x[0]) if x else [])'
```

## 에이전트 전달 규칙

1. 사용자 제공 가사와 음정이 있으면 그대로 우선한다. 곡 제목만 있으면 조회 결과를 곡 후보로 제시하거나 권한 있는 자료 제공을 요청한다.
2. LRC 줄 시작만 있으면 그 값을 음절별 주파수로 바꾸지 않는다. 음정이나 세부 타이밍이 빠진 경우에는 추정·새 창작임을 분명히 하거나 필요한 입력을 요청한다. 정확한 악보 재현이 목표라면 추정으로 대체하지 않는다.
3. 도서·음원 서비스의 로그인, 비공개 API, DRM을 우회하지 않는다. 401/403/429는 “지원됨”이 아니다. 권한·비용·이용약관을 확인하고 필요하면 추후 계약을 요청한다.
4. 로컬에서 음원만 낼지 프로그램 화면까지 렌더할지 구분한다. 외부 공개와 외부 전송은 별개다. 반환 전 음원 길이·권한·생성물 경로를 확인한다.
